* cassels_swinnerton_dyer_cubic_surfaces.pdf provides a solution to the Cassels-Swinnerton-Dyer conjecture for cubic surfaces.

The Sep 9 version corrects some of the attributions following the comments I received: the d=4 to d=5 equivalence is due to Cassels, and Coray proved the case of a singular cubic surface over a perfect field.

* towards_cassels_swinnerton_dyer_cubic_threefolds provides some partial results for the 3-dimensional case.
